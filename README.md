# pizza-shop

Лендинг пиццерии. Одна страница: шапка, промо, меню, события, о компании и подвал.

Макет свёрстан как десктоп. Адаптивных брейкпоинтов нет.

## Технологии

- React 19 и TypeScript
- Vite 8
- CSS Modules
- Montserrat (woff2) из `public/fonts`, подключение в `src/styles/fonts`
- ESLint, Stylelint, Prettier

Цвета лежат в `src/styles/variables/colors.css`.

## Что сделано

Страница собирается в `src/App.tsx` из блоков:

| Блок   | Содержание                                                       |
| ------ | ---------------------------------------------------------------- |
| Header | Логотип, навигация, вход и корзина                               |
| Promo  | Заголовок, описание, превью готовки, кнопки и большое фото       |
| Menu   | Фильтры, 8 пицц, выбор размера и количества, баннер Most Popular |
| Events | Сетка из 7 карточек и три декорации поверх блока                 |
| About  | Текст, ряд из пяти пицц и большое фото                           |
| Footer | Колонки ссылок, телефон `+7 (000) 000-00-00`, соцсети            |

Картинки лежат в `public/images`.

## Ширина

Медиазапросов в стилях нет. Две фиксированные ширины:

- **1512px** — холст `.app`, по центру окна. Фон страницы — тёплый градиент на всю ширину окна, в том числе по бокам от холста.
- **1252px** — Promo, Menu, Events, About и Footer, по центру холста.

Шапка на всю ширину холста, боковые отступы по 80px.

## GitHub Pages

Workflow `.github/workflows/deploy.yml` собирает проект на пуше в `main` и публикует `dist`.

В CI `base` равен `/имя-репозитория/`, собранные файлы кладутся в `assets`. Пути картинок и шрифтов получают тот же префикс, поэтому на Pages они открываются. Локально префикса нет.

В настройках репозитория источник Pages — GitHub Actions.
